# PiTV v1.3.1 Beta

Lehký TV launcher a 24/7 serverové prostředí pro Raspberry Pi 4.

### Co je nové
- opravené nastavení Wi-Fi v **PiTV SD Installeru**
- SSID a heslo lze zadat ručně nebo načíst z Windows
- launcher při spuštění automaticky použije **nejnovější release**
- zachovaná možnost **NAFORMÁTOVAT SD**

### Instalace
Stáhni jediný soubor **PiTV-SD-Installer-Windows-v1.3.1.zip**, rozbal ho a spusť `Start-PiTV-SD-Installer.cmd`.

> Beta: automatické testy procházejí, fyzické HDMI/CEC/Waydroid ověření na Raspberry Pi 4 pokračuje.
