# PiTV v1.3.0

První veřejný beta release samostatného projektu **CaseyCZ/PiTV** pro Raspberry Pi 4.

PiTV kombinuje lehké TV rozhraní nad Ubuntu Server 24.04 ARM64 s HDMI-CEC ovládáním, PiTV Store, Server Store a volitelným Waydroidem / Google Play.

## Doporučená instalace

### Windows

Stáhni:

**PiTV-SD-Installer-Windows-v1.3.0.zip**

Rozbal ZIP, vlož microSD kartu a spusť:

`Start-PiTV-SD-Installer.cmd`

Windows GUI umí:

- najít bezpečné výměnné SD / USB zařízení,
- připravit Ubuntu Server 24.04 ARM64,
- převzít Wi-Fi nastavení,
- připravit automatickou první instalaci PiTV,
- samostatně obnovit / naformátovat SD kartu jako exFAT `SDCARD`.

### Linux / macOS

Stáhni `pitv-flasher.sh`, nastav spustitelnost a spusť:

```bash
chmod +x pitv-flasher.sh
./pitv-flasher.sh
```

### Windows PowerShell CLI

K dispozici je také `pitv-flasher.ps1`.

## Co release obsahuje

- PiTV Apple Dark / Apple Light
- HDMI-CEC navigaci a TV audio
- PiTV Store: Kodi, SmartTube, Stremio, YouTube, Spotify a Plex
- Server Store: Homebridge, Tailscale, Docker Engine a ATVLoadly
- Waydroid + Google Play
- Waydroid fallback snapshot pro Ubuntu 24.04 / ARM64
- automatický PiTV self-update
- PiTV SD Installer pro Windows, Linux a macOS
- možnost bezpečně obnovit / naformátovat SD kartu
- SHA-256 kontrolní součty release souborů

## Ověření stažených souborů

Soubor `SHA256SUMS.txt` obsahuje kontrolní součty všech distribuovaných instalačních souborů.

Na Linuxu/macOS:

```bash
sha256sum -c SHA256SUMS.txt
```

Ve Windows lze jednotlivý soubor zkontrolovat například:

```powershell
Get-FileHash .\PiTV-SD-Installer-Windows-v1.3.0.zip -Algorithm SHA256
```

a hodnotu porovnat se `SHA256SUMS.txt`.

## Stav

Tento release je označený jako **Beta**.

Automatické CI testy prošly na Ubuntu 24.04 x64 i ARM64. Fyzický Raspberry Pi 4 je ještě potřeba finálně ověřit pro konkrétní HDMI/KMS výstup, HDMI-CEC TV, HDMI audio, Kodi hardware decode a Waydroid GPU/kernel chování.
