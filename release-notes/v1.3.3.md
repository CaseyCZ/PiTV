# PiTV v1.3.3 Beta

Oprava automatické instalace Raspberry Pi Imageru ve Windows.

### Opraveno
- podpora nové cesty Raspberry Pi Imager 2.x
- fallback na přímé stažení oficiálního `imager_latest.exe`
- lepší chybové hlášení při selhání instalace

### Instalace
Stáhni **PiTV-SD-Installer-Windows-v1.3.3.zip**, rozbal ho a spusť `Start-PiTV-SD-Installer.cmd`.
