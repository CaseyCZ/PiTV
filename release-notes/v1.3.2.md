# PiTV v1.3.2 Beta

Malý patch pro pohodlnější přípravu microSD ve Windows.

### Co je nové
- automatické vyhledání dostupných Wi‑Fi sítí
- doplnění uložených Windows Wi‑Fi profilů
- automatické načtení uloženého hesla, pokud ho Windows zná
- nové **Zobrazit heslo** pro kontrolu před zápisem
- ruční SSID a heslo zůstává vždy dostupné

### Instalace
Stáhni **PiTV-SD-Installer-Windows-v1.3.2.zip**, rozbal ho a spusť `Start-PiTV-SD-Installer.cmd`.

Launcher si při dalším spuštění vždy zkontroluje nejnovější GitHub Release.
